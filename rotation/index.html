Data

The volume as one PDF is a file of this site. The other files are those of the repository at commit 119ff5dc: a PDF is a copy on this site and opens in a tab of its own, and any other file downloads from GitHub.

The volume as one PDF (2023 sheets) holds the conventions, the documents of its groups, the references and the index of notation. CONVENTIONS.pdf is CONVENTIONS.md typeset, the file point_groups.json holds the lattice of the O(3)-conjugacy classes of the point groups, and the schemas are those of this volume's records. The Data section of each group lists the group's own files.

The symmetry-adapted bases for J = 11, 12, …, 60, too large for the repository, are attached to its release bases, one archive for each group. The file index.json gives the size and SHA-256 digest of each file of the records, of each volume's conventions, lattice and record schemas, and of the README, the references and the license. For each record it also lists the records that the record names.
