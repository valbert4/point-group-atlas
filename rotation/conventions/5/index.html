5 Conjugacy classes ¶

5.1 The symbol of an operation ¶

The symbol is a function of det⁡\det and the turn p/qp/q in lowest terms:

  1. det⁡=+1\det = +1: E if q=1q = 1; C_q if p=1p = 1; else C_q^p;
  2. det⁡=−1\det = -1: a mirror if q=1q = 1; i if (q,p)=(2,1)(q, p) = (2, 1); else S_q^j with j=pj = p for odd pp and j=p+qj = p + q for even pp (S_q when j=1j = 1), so the exponent is odd (𝘚𝟥𝟧\mathsfit{S_{3}^{5}} in 𝖢𝟥𝗁\mathsf{C_{3h}}).

5.2 Fields of character_table.classes[] ¶

  1. label: the symbol of the member whose (qq, exponent) is lexicographically smallest, prefixed by the class size when it exceeds 1 ("8C_3", "2S_8^3"), with these names for mirrors and binary axes:

    1. axial groups: the class of σ𝘻\mathsfit{\sigma_{z}} is sigma_h; a class of vertical mirrors is sigma_v if it contains σ𝘷(0)\mathsfit{\sigma_{v}}(0) and sigma_d otherwise; of two classes of binary rotations about horizontal axes, the one containing 𝘊𝟤𝘹\mathsfit{C_{2x}} is C_2' and the other C_2''; a single such class is C_2' if 𝘊𝟤𝘻∈𝖦\mathsfit{C_{2z}} \in \mathsf{G} and C_2 otherwise;
    2. 𝖳𝗁\mathsf{T_{h}}, 𝖳𝖽\mathsf{T_{d}}, 𝖮𝗁\mathsf{O_{h}}: sigma_h when the normals of the planes lie along the coordinate axes, sigma_d otherwise; 𝖨𝗁\mathsf{I_{h}}: sigma.
  2. angle: [p, q], the turn of the member that the symbol names. det, size, element_order: the determinant, the number of elements and the order of the elements of the class.
  3. id: the label without its size prefix, with sigma written s, ' written p and every other character that is not a letter or a digit removed (C_3^2 →\to C32, sigma_d →\to sd, C_2'' →\to C2pp); when two classes would get the same id, both have their size appended (𝖮\mathsf{O}: C23 for 𝟥𝘊𝟤\mathsfit{3C_{2}}, C26 for 𝟨𝘊𝟤\mathsfit{6C_{2}}).
  4. display: the label in LaTeX ("8C_{3}", "3\\sigma_{h}" in JSON).
  5. axis_order_n: the order of the rotation (det⁡𝘨) 𝘨(\det \mathsfit{g})\,\mathsfit{g}, 𝘨\mathsfit{g} in the class: the denominator of p/qp/q for a proper class and of p/q+1/2p/q + 1/2 for an improper one (𝘌\mathsfit{E} and 𝘪\mathsfit{i}: 1, a mirror: 2, 𝘚𝟦\mathsfit{S_{4}}: 4, 𝘚𝟨\mathsfit{S_{6}}: 3).
  6. axis_type: "identity" (𝘌\mathsfit{E}), "inversion" (𝘪\mathsfit{i}); axial groups: "principal" (the operations about zz other than 𝘌\mathsfit{E}, 𝘪\mathsfit{i} and σ𝘩\mathsfit{\sigma_{h}}), "horizontal-mirror" (σ𝘩\mathsfit{\sigma_{h}}), "perpendicular" (binary rotations about horizontal axes), "vertical-mirror" (mirrors containing zz); exceptional groups: "rotation-axis" (every class other than 𝘌\mathsfit{E}, 𝘪\mathsfit{i} and the mirrors), "cube-axis-mirror" (σ𝘩\mathsfit{\sigma_{h}} of 𝖳𝗁\mathsf{T_{h}} and 𝖮𝗁\mathsf{O_{h}}), "diagonal-mirror" (σ𝘥\mathsfit{\sigma_{d}} of 𝖳𝖽\mathsf{T_{d}} and 𝖮𝗁\mathsf{O_{h}}), "mirror" (σ\mathsfit{\sigma} of 𝖨𝗁\mathsf{I_{h}}).

  7. pole: the pole (section 4.2) of a member at the class's own angle, except for 𝘪\mathsfit{i} in an axial group, which carries the principal axis as the rotoreflection 𝘚𝘻(π)\mathsfit{S_{z}}(\pi) about it:

    1. {"kind": "none"} for 𝘌\mathsfit{E}, and for 𝘪\mathsfit{i} in the exceptional groups; 𝘪\mathsfit{i} of an axial group has {"kind": "axis", "cartesian": [0, 0, 1]};
    2. axial groups: the classes about zz have cartesian [0, 0, 1] (kind plane_normal for σ𝘩\mathsfit{\sigma_{h}}, axis otherwise); a "perpendicular" class has {"kind": "axis", "azimuth_turn": [p, q]}, the azimuth of a binary axis, and a "vertical-mirror" class has {"kind": "plane_normal_in_xy", "azimuth_turn": [p, q]}, the azimuth of the horizontal direction that lies in a mirror plane, each the smallest such azimuth among the members, in [0,1/2)[0, 1/2);
    3. exceptional groups: the member pole whose unit direction comes first in the order of largest zz, then largest xx, then largest yy.
  8. power_map: the id of the class of 𝘨2\mathsfit{g}^2, 𝘨\mathsfit{g} in the class. inverse_class: the id of the class of 𝘨−1\mathsfit{g}^{-1}. ambivalent: whether inverse_class is the class itself.

class_count is the number of classes.

5.3 Class order ¶
