5 Conjugacy classes ¶

5.1 The symbol of an operation ¶

The symbol is a function of det⁡\det and the turn p/qp/q in lowest terms:

  1. det⁡=+1\det = +1: E if q=1q = 1, C_q if p=1p = 1 and C_q^p otherwise.
  2. det⁡=−1\det = -1: a mirror if q=1q = 1, i if (q,p)=(2,1)(q, p) = (2, 1) and S_q^j otherwise, with j=pj = p for odd pp and j=p+qj = p + q for even pp (S_q when j=1j = 1). Thus the exponent is odd (𝘚𝟥𝟧\mathsfit{S_{3}^{5}} in 𝖢𝟥𝗁\mathsf{C_{3h}}).

5.2 Fields of character_table.classes[] ¶

  1. label: the symbol of the member whose (qq, exponent) is lexicographically smallest, prefixed by the class size when it exceeds 1 ("8C_3", "2S_8^3"), with these names for mirrors and binary axes:

    1. Axial groups: the class of σ𝘻\mathsfit{\sigma_{z}} is sigma_h. A class of vertical mirrors is sigma_v if it contains σ𝘷(0)\mathsfit{\sigma_{v}}(0) and sigma_d otherwise. Of two classes of binary rotations about horizontal axes, the class containing 𝘊𝟤𝘹\mathsfit{C_{2x}} is C_2' and the other C_2''. A single such class is C_2' if 𝘊𝟤𝘻∈𝖦\mathsfit{C_{2z}} \in \mathsf{G} and C_2 otherwise.
    2. 𝖳𝗁\mathsf{T_{h}}, 𝖳𝖽\mathsf{T_{d}}, 𝖮𝗁\mathsf{O_{h}}: sigma_h when the normals of the planes lie along the coordinate axes, sigma_d otherwise.
    3. 𝖨𝗁\mathsf{I_{h}}: sigma.
  2. angle: [p, q], the turn of the member named by the symbol.
  3. det, size, element_order: the determinant, the number of elements and the order of the elements of the class.
  4. centralizer_order: the order of the centralizer in 𝖦\mathsf{G} of an element of the class, ∣𝖦∣\lvert \mathsf{G}\rvert divided by size.
  5. id: the label without its size prefix, with sigma written s, ' written p and every other character that is not a letter or digit removed (C_3^2 →\to C32, sigma_d →\to sd, C_2'' →\to C2pp). When two classes would get the same id, both have their size appended (𝖮\mathsf{O}: C23 for 𝟥𝘊𝟤\mathsfit{3C_{2}}, C26 for 𝟨𝘊𝟤\mathsfit{6C_{2}}).
  6. display: the label in LaTeX ("8C_{3}", "3\\sigma_{h}" in JSON).
  7. axis_order_n: the order of the rotation part (det⁡𝘨) 𝘨(\det \mathsfit{g})\,\mathsfit{g} for 𝘨\mathsfit{g} in the class. It is the denominator of p/qp/q for a proper class and of p/q+1/2p/q + 1/2 for an improper one (1 for 𝘌\mathsfit{E} and 𝘪\mathsfit{i}, 2 for a mirror, 4 for 𝘚𝟦\mathsfit{S_{4}} and 3 for 𝘚𝟨\mathsfit{S_{6}}).

  8. axis_type: "identity" (𝘌\mathsfit{E}), "inversion" (𝘪\mathsfit{i}) and these values:

    1. Axial groups: "principal" (the operations about zz other than 𝘌\mathsfit{E}, 𝘪\mathsfit{i} and σ𝘩\mathsfit{\sigma_{h}}), "horizontal-mirror" (σ𝘩\mathsfit{\sigma_{h}}), "perpendicular" (binary rotations about horizontal axes), "vertical-mirror" (mirrors containing zz).
    2. Exceptional groups: "rotation-axis" (every class other than 𝘌\mathsfit{E}, 𝘪\mathsfit{i} and the mirrors), "cube-axis-mirror" (σ𝘩\mathsfit{\sigma_{h}} of 𝖳𝗁\mathsf{T_{h}} and 𝖮𝗁\mathsf{O_{h}}), "diagonal-mirror" (σ𝘥\mathsfit{\sigma_{d}} of 𝖳𝖽\mathsf{T_{d}} and 𝖮𝗁\mathsf{O_{h}}), "mirror" (σ\mathsfit{\sigma} of 𝖨𝗁\mathsf{I_{h}}).

  9. pole: the pole (section 4.2) of a member at the class's own angle, except for 𝘪\mathsfit{i} in an axial group, which carries the principal axis as the rotoreflection 𝘚𝘻(π)\mathsfit{S_{z}}(\pi) about it:

    1. {"kind": "none"} for 𝘌\mathsfit{E}, and for 𝘪\mathsfit{i} in the exceptional groups. In an axial group, 𝘪\mathsfit{i} has {"kind": "axis", "cartesian": [0, 0, 1]}.
    2. Axial groups: the classes about zz have cartesian [0, 0, 1] (kind plane_normal for σ𝘩\mathsfit{\sigma_{h}}, axis otherwise). A "perpendicular" class has {"kind": "axis", "azimuth_turn": [p, q]}, the azimuth of a binary axis, and a "vertical-mirror" class has {"kind": "plane_normal_in_xy", "azimuth_turn": [p, q]}, the azimuth of the horizontal direction in a mirror plane. Each azimuth is the smallest among the members, in [0,1/2)[0, 1/2).
    3. Exceptional groups: the member pole whose unit direction comes first in the order of largest zz, then largest xx, then largest yy.
  10. power_map: the id of the class of 𝘨2\mathsfit{g}^2, 𝘨\mathsfit{g} in the class.
  11. power_maps: for each prime pp that divides ∣𝖦∣\lvert \mathsf{G}\rvert, the id of the class of the ppth powers of the elements of the class, under the key pp in decimal ("2", "3"). The value at "2" is power_map.
  12. inverse_class: the id of the class of 𝘨−1\mathsfit{g}^{-1}.
  13. ambivalent: whether inverse_class is the class itself.

The number of classes is class_count.

The class 2C_2' of 𝖣𝟦\mathsf{D_{4}} in [Gri61, Table A 3] is the class 𝟤𝘊𝟤′′\mathsfit{2C_{2}''} of the diagonal axes here, and [Gri61, Table A 5] writes 6C_2' for the class 𝟨𝘊𝟤\mathsfit{6C_{2}} of 𝖮\mathsf{O}.

5.3 Class order ¶

The order of character_table.classes is the order of every list of characters. Axial groups order their classes by ascending key, where ωmin⁡\omega_{\min} is the smallest angle among the members of the class:

keyclasses
(0)(0)𝘌\mathsfit{E}
(1,ωmin⁡)(1, \omega_{\min})proper rotations about zz
(2,0)(2, 0), (2,1)(2, 1)𝘊𝟤′\mathsfit{C_{2}'} (or 𝘊𝟤\mathsfit{C_{2}}), then 𝘊𝟤′′\mathsfit{C_{2}''}
(3)(3)𝘪\mathsfit{i}
(4,ωmin⁡)(4, \omega_{\min})improper operations about zz other than 𝘪\mathsfit{i}: σ𝘩\mathsfit{\sigma_{h}} (ωmin⁡=0\omega_{\min} = 0), then the 𝘚nk\mathsfit{S_{\mathnormal{n}}^{\mathnormal{k}}} classes
(5,0)(5, 0), (5,1)(5, 1)σ𝘷\mathsfit{\sigma_{v}}, then σ𝘥\mathsfit{\sigma_{d}}

Exceptional groups put 𝘌\mathsfit{E} first, then the proper classes by decreasing axis_order_n, 𝘪\mathsfit{i}, the improper classes other than the mirrors by decreasing axis_order_n, and the mirrors (σ𝘩\mathsfit{\sigma_{h}} before σ𝘥\mathsfit{\sigma_{d}}). In full:
