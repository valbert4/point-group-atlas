Conventions

This document defines the fields of the data of the point groups and, in section 0, the notation common to their documents. The file double/CONVENTIONS.md (sections 20 to 29) defines the fields of the data of the double point groups and its additions to the notation. The file magnetic/CONVENTIONS.md (sections 30 to 39) defines the fields of the data of the magnetic point groups and its additions to the notation. The index of notation lists the common notation and selected symbols of the sections, each with the section that defines it. The records, the schemas and the LaTeX files refer to the sections by number.
