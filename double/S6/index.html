Data

The files are those of the repository at commit 119ff5dc: the PDF is a copy on this site and opens in a tab of its own, and any other file downloads from GitHub. The GAP, Wolfram Language and SymPy files hold the record as one literal bound to o3d, under the same keys as the JSON file. Under the title of each section, a line names the fields that the section reads and the files that hold them.

The schema of the record is section.schema.json, and the record names 2S6 and S6. The file index.json gives the size and SHA-256 digest of each file of the records, of each volume's conventions, lattice and record schemas, and of the README, the references and the license. For each record it also lists the records that the record names.
